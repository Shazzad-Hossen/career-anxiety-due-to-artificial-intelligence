# Career Anxiety Due to AI — Data Visualization Notebook

## 📌 Overview
This notebook explores **career anxiety caused by the rise of Artificial Intelligence (AI)** through data visualization. It analyzes survey or dataset-driven insights to understand how individuals perceive AI’s impact on jobs, skills, and future career stability.

The goal of this project is to transform raw data into **clear, interpretable visual insights** that highlight trends, concerns, and patterns related to AI-driven career uncertainty.

---

## 📊 What This Notebook Does
- Cleans and preprocesses the dataset
- Analyzes responses related to:
  - Job security
  - Fear of automation
  - Skill relevance
  - Career confidence
- Uses visualizations to:
  - Identify trends and distributions
  - Compare different groups or responses
  - Highlight key insights in an intuitive way
